# Rota heterogênea

Decomposição, planejamento de rota e explicação por agentes LLM e BDI.

## Executar

Da raiz do repositório:

```sh
./ariadne scenario heterogeneous-route
```

Requer credencial do provedor para as etapas LLM e pode gerar custos.
