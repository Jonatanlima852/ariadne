# Contrato protobuf

[contract/v1/contract.proto](contract/v1/contract.proto) define os serviços e
mensagens compartilhados por runtime e agentes. [VERSION](contract/v1/VERSION)
registra a versão (atualmente `2.0.0`) e [contract.sha256](contract/v1/contract.sha256)
seu checksum.

A [referência pública](../docs/reference.md) explica as APIs e políticas.
Para alterar ou regenerar stubs, consulte o
[guia de desenvolvimento](../docs/development.md#alterações-no-contrato).
